# StudyLog 

A Python-based study tracker that helps students manage study sessions, track study time by subject, and monitor daily progress.

## Features
- Countdown study timer
- Pause, resume, and stop study sessions
- Track study time by subject
- Save and load study history
- View daily study summaries and total study time
- Support multiple study sessions

## Technologies Used
- Python
- Threading
- File Handling
- Git & GitHub

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/pujarai7000/StudyLog.git
   ```
2. Navigate to the project folder:
   ```bash
   cd StudyLog
   ```
3. Create an empty `study_history.txt` file if it doesn't exist.
4. Run the program on Windows:
   ```bash
   python studyTracker.py
   ```

## Timer Controls
- `p` — Pause
- `r` — Resume
- `s` — Stop
